What This Template Creates (AWS S3 Static Website):

✅ 1 S3 bucket configured for static website hosting  
✅ Public bucket policy allowing read access to objects (for website)  
✅ Website index and error pages configured  
✅ Optional example index.html object stored in the bucket  
✅ Useful outputs: bucket name and website endpoint

⚠ Note: This template creates a PUBLIC S3 website (anyone on the internet can read objects).
Use only for public/static content and never for sensitive data.
